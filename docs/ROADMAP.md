# 法律智能问答系统 —— 重做路线图（Rebuild Roadmap）

> 目标：从零重建一个**真实可运行、可演示、可开源**的法律智能问答系统，
> 覆盖简历上的每一个技术点，让每个细节都能经得起面试追问。

## 一、系统架构总览

```
用户浏览器
   │  HTTP / JSON
   ▼
┌─────────────────────────────────────────────┐
│  Flask 后端 (app/)                            │
│  ├─ /api/chat        多轮对话入口             │
│  ├─ /api/intent      意图识别（Bert 微调模型） │
│  └─ /api/health      健康检查                 │
└──────┬───────────────────────┬──────────────┘
       │                       │
       ▼                       ▼
┌──────────────┐      ┌────────────────────────┐
│ 意图识别服务   │      │ 多轮对话管理器            │
│ Bert 分类模型  │      │ (session + 槽位追踪)     │
│ (intent_model)│     └──────────┬─────────────┘
└──────────────┘               │
                               ▼
                    ┌────────────────────┐
                    │ Neo4j 法律知识图谱   │
                    │ 法条 / 罪名 / 概念   │
                    │ (knowledge_graph/)  │
                    └────────────────────┘
```

## 二、技术栈（与简历严格对齐）

| 模块 | 技术 | 说明 |
|---|---|---|
| 后端 | Python 3.12 + Flask | REST API、跨域、会话管理 |
| 意图识别 | bert-base-chinese 微调 | 法律咨询意图多分类，目标准确率 ≥90% |
| 知识图谱 | Neo4j | 法条/罪名/概念节点 + 关系，Cypher 检索 |
| 多轮对话 | 自研对话管理器 | 槽位填充、上下文继承、指代消解（基础版） |
| 前端 | HTML + JS（简洁聊天界面） | 与后端接口联调 |
| 测试 | pytest | 意图识别、图谱检索、对话流测试用例 |

## 三、开发步骤（每一步都有可验证产出）

1. **环境准备**：项目 venv、安装依赖（flask / torch / transformers / neo4j / pytest）
2. **意图数据集**：构造法律领域意图分类数据集（≥10 类意图、每类 ≥100 条，共 1000+ 条）
3. **Bert 微调**：训练 + 评估（准确率/混淆矩阵），导出模型
4. **法律知识图谱**：设计 Schema（法条/罪名/构成要件/量刑），Cypher 导入脚本 + 数据
5. **问答引擎**：意图 → 槽位提取 → Cypher 查询 → 答案模板生成
6. **多轮对话管理**：会话状态、槽位继承、追问处理
7. **Flask 后端**：API 组装、接口联调
8. **前端页面**：聊天界面联调
9. **测试与文档**：pytest 用例、README、技术文档、接口文档
10. **开源发布**：Git 初始化、LICENSE、.gitignore、推送 GitHub
